# Contributing

Thanks for taking an interest in the project!

## Before Contributing

Please read the [README](README.md) and [LICENSE](LICENSE.md) first.

## Guidelines

- Keep changes focused and easy to understand.
- Use clear names for files, functions, and variables.
- Avoid unnecessary changes to unrelated files.
- Test changes before submitting them.
- Update documentation when a change affects how the project is used.
- Respect third-party licenses and attribution requirements.
- Do not submit code intended to steal accounts, credentials, personal information, or otherwise harm users.

## Commit Messages

Use short, descriptive commit messages. Examples:

```text
feat: add settings documentation
fix: correct loadstring issue
docs: update README
refactor: reorganize source files
```

## Pull Requests

When proposing a change, explain:

1. What you changed.
2. Why you changed it.
3. How you tested it.
4. Any documentation that was updated.

## Ideas and Suggestions

Ideas that are not ready for implementation can be added to `docs/ideas.md`.

Thanks for helping keep the project organized! 🚀
