## 🏷️ Versioning

Version numbers are used to make project changes easier to understand:

- **Major** — Significant changes or breaking changes.
- **Minor** — New features and notable improvements.
- **Patch** — Bug fixes and small changes.

Example:

```text
1.0.0 → Initial release
1.1.0 → New features and improvements
1.1.1 → Bug fixes
2.0.0 → Major changes
```
